Spesifikasi Endpoint API (Pola ECS BSrE)

POST /api/v1/sign

Kirim nilai hash dokumen untuk mendapatkan tanda tangan ML-DSA:

{
  "signer_id": "rplk2-bsre",
  "algorithm": "ML-DSA-65",
  "digest": "<SHA-256-HEX>",
  "format": "raw"
}
POST /api/v1/verify

Verifikasi tanda tangan digital terhadap data atau hash:

{
  "algorithm": "ML-DSA-65",
  "digest": "<SHA-256-HEX>",
  "public_key": "<HEX-STRING>",
  "signature": "<HEX-STRING>"
}
